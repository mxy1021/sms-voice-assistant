## 建议执行顺序

1. 先收尾模拟工具与听感：三种短业务已确认；D12静态断连通过；D13真实系统焦点暂停/恢复及超时已补。保留长样例UNSUPPORTED。
2. 决定A/B全文验收范围；不决定则全文持续部分完成。
3. 少量真实SMS优先覆盖原故障：精简验证码、短验证码全文、短普通全文各一条，保留系统通知音。停止样本可与其他场景合并；不要求重复45次发送。
4. 用户人工动态断连/改路由、正常播放中停止；可先以固定模拟输入观察安全性，再少量真实SMS复核。
5. 物理断USB：Home、锁屏、静置10～15分钟、音乐、断连/重连组合验证；分别记录场景及听感。
6. 重启解锁后先不开APP接收真实SMS；冷进程及运营商多段另安排。故障注入只补实际能控制的场景，未执行保持未验证。
