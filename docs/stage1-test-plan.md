## 可执行检查

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug --console=plain
python scripts/Test-Stage1Device.py
python scripts/Test-Stage1Device.py --ui-smoke
```

脚本只选择唯一在线授权的预期 vivo 真机，忽略离线模拟器；读取系统、受限的配置布尔状态；不输出序列号/MAC/短信。`--ui-smoke` 会打开APP，短暂切换筛选并在 finally 恢复；请保持手机空闲、解锁。额外的 `--set-enabled true|false`、`--set-boot-restore true|false` 通过真实界面修改对应配置，需明确知道会改变工作状态。脚本不发短信、不授权、不安装、不重启、不清数据。证据在被忽略的 app/build/stage1-device。

安装先在本地用 adb devices -l 确认目标，再用本地选定的设备变量（不提交其实际值）：

```powershell
adb -s $svaDevice install -r app/build/outputs/apk/debug/app-debug.apk
adb -s $svaDevice shell am start -n com.mxy1021.smsvoiceassistant/.MainActivity
```

签名冲突必须停止，不得卸载或换签名。安装弹窗由用户确认。权限只通过系统正常授权，不用 pm grant/白名单/关闭 AudioHardening。脱敏时序使用既有 scripts/Read-Stage0Log.ps1，不收集完整 Logcat。

## 人工操作批次

1. 连接目标耳机，确认权限与 OriginOS“允许后台高耗电”，启用运行。发送新的真实普通蜂窝SMS（另一端发送，不用模拟广播），只反馈用例编号与结果，不提供正文/号码/真实码。
2. 开/开：发送验证码、普通SMS；应分别精简/静默。开/关：短验证码应读完整原文含安全提醒，普通SMS静默。关/任意：短普通SMS和验证码均读完整原文；精简控件禁用；重新开启筛选保留值。
3. 各模式下停止后发送短信，必须静默；再启用恢复。播放中停止，确认立即终止、音乐恢复。选择长全文时应显示整条拒绝，不把片段听感判成功。
4. Home、Home后锁屏、静置10～15分钟分别发送验证码；目标耳机断开后收短信须无扬声器声音，重连后恢复。播放中断连/切路由分别记录。音乐场景确认降低、结束/取消后恢复。
5. 运营商真实多段短信核查顺序、完整性、无重复；输入上限和5秒音频边界分别看脱敏终结状态。重复3轮不代表全部生命周期边界通过。
6. 重启需用户事先确认，每次用户手动解锁，重新读取ADB/API/开机计数、配置和权限。不主动打开APP先观察开机事件，再启动核查兜底；不能用 am broadcast 宣称开机通过。
7. 最后**物理断开USB**，Home、锁屏、静置、断开/重连耳机、音乐期间各发新SMS。用户回报听感和静默，USB连接下结果不能替代。
