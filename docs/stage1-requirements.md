## 基线与最高优先级

- 唯一工程目录为现有 SMSVoiceAssistant，单模块 Kotlin、Compose、Material3、Gradle Kotlin DSL。
- applicationId `com.mxy1021.smsvoiceassistant`；min/target/compile 33/34/36，签名与依赖基线不变。
- 保留阶段0事件链：新 SMS → PDU → 规则 → 指定蓝牙连接/预期路由 → 严格离线中文 TTS → 内存 PCM → MAY_DUCK → AudioTrack 静音探测实际路由 → PCM → 清理。
- 无 Service、FGS、轮询、联网、云端、Root、系统签名、默认短信角色；不修改媒体音量或控制其他播放器。
- 不读历史短信，不保存/打印/上传正文、验证码、发送方、号码或语音文件。TTS 继续向 `/dev/null` 合成，PCM 只在内存。
- 仅 RECEIVE_SMS、BLUETOOTH_CONNECT；为开机后状态处理增加普通权限 RECEIVE_BOOT_COMPLETED。不增加其他请求权限。

## 配置与运行

SettingsRepository 是唯一正式配置入口；沿用私有 `stage0` SharedPreferences，旧 `target` 原位复用，无跨存储迁移、双写或耳机身份替换。新设置使用独立键，默认值不会覆盖已有值；`settingsVersion=1` 标记格式，`setupCompleted` 记录已完成目标选择/首次启用。

| 配置 | 新安装默认值 | 语义 |
|---|---|---|
| announcingEnabled | false | 新 SMS 总入口及每次 PCM 写入门禁 |
| otpOnlyEnabled | true | 仅可靠识别的验证码可进入播报 |
| otpSimplifyEnabled | true | 筛选开启时决定精简/全文 |
| bootRestoreEnabled | false | 重启后是否保留上次运行状态 |
| selectedBluetoothDevice | 未设置 | 存储键继续为 target，按地址身份匹配 |

阶段0没有正式总开关，升级时同样从暂停开始，要求用户显式启用；旧耳机保留。Home、锁屏、正常进程重建不改运行设置。停止先撤销播放许可，再取消会话并释放资源。设置代次与非阻塞 PCM 写入共享锁，停止返回后旧会话不能再写入 PCM；重新启用也不能复活旧许可。更改规则或耳机同样使在途许可失效。忙碌时拒绝新任务，不排队重播旧验证码。

## 三种短信行为

| 仅播报验证码 | 精简验证码播报 | 实际行为 |
|---|---|---|
| 开 | 开 | 可靠验证码 → 平台及验证码精简语音 |
| 开 | 关 | 可靠验证码 → 正文全文 |
| 关 | 保留任意原值 | 所有新普通 SMS → 正文全文 |

第二开关始终可见；筛选关闭时禁用，保存值保留，重新筛选后恢复。总开关优先级最高。不另设三模式选择器。

OtpDetector / OtpExtractor / SpeechFormatter 分离识别与选文。基础识别支持紧邻“验证码/校验码/动态码”的4、6、8位数字，以及4～8位且含数字的字母数字组合；可有冒号、空格、“为/是”。开头 `【平台】` 提取有限平台名，未知平台用通用语句。数字逐位，英文字母按大小写逐个读出。拒绝多个候选、超长数字、金额/日期后缀和明显多候选连接；不从无关键词的订单/号码/金额中选第一组数字。

复杂模板、纯字母码、模糊语义、跨语言完整规则引擎留待后续；基础规则不能承诺识别所有验证码。全文直接使用完整原始正文，不摘要、不删安全提醒、不改数字字母、不截断。

只处理系统 SMS_RECEIVED 的新普通 SMS，不处理 MMS/RCS/其他 APP 通知。单次广播按 Android 框架提供的顺序组合；要求发送方非空且一致、时间戳一致、片段非空，最多16段/2048字符。不在应用内跨广播拼接。不同时间戳片段保守拒绝；该严格边界需运营商真短信确认。有限进程内加盐摘要防重复，不保存短信摘要至磁盘；进程重建后的重复投递不保证全局去重。

## 全文与生命周期范围

用户于2026-11-11正式选择**方案B：阶段1接受有限长度全文MVP**，覆盖此前任意长度全文的要求；范围接受不是整体验收通过。最多80个UTF-16代码单元只是输入准入上限，不是80代码单元一定能播完的保证。实际完整 PCM 必须≤1MiB、16位单/双声道、8～48kHz、语音≤5秒，且当前已用时间 + 完整语音 + 700ms 路由/清理余量 < 8秒。在合成完成、实际路由确认后分别检查；超限在写入任何语音前整条拒绝，UI显示拒绝原因。不得将安全拒绝当全文成功。

保留接收时起算8秒 elapsedRealtime 总预算和120秒 PDU 临时有效期；冻结恢复后重新检查。播放期间超时/停止/权限撤销/路由变化则终止并记未完成；不能把已开始后被中断的片段标成功。系统调度、音频回调和缓冲存在窗口，不能承诺动态断连零泄漏。较长/任意长度全文尚未实现，列为后续独立技术专项，不构成阶段1的范围阻塞；本阶段不实施该专项或改变无Service架构。D02/D04/D05/D07/D09实测PCM分别为7.707/7.787/8.227/17.227/8.107秒，均超限整条拒绝，未写入语音；D05说明识别出混合验证码也不保证能在音频预算内播报。

Android [goAsync 生命周期约束](https://developer.android.com/reference/android/content/BroadcastReceiver#goAsync())持续适用；[Android17后台音频限制](https://developer.android.com/about/versions/17/changes/bg-audio)独立于 target34。保持现有无 Service 方案，目标机成功不能推广为其他设备保证，不关闭 AudioHardening。

## 正式界面与系统设置

Compose Material3 明暗主题、滚动布局及安全区域适配。运行卡显示暂停、权限缺失、未选择、未连接、路由不匹配、检查中、准备/播报中、启用等待；最近处理状态显示拒绝或完成回调。不会显示“后台服务运行”。

耳机卡只列已配对设备，展示名称、连接和预期路由，按地址保存；手动刷新、返回前台及音频设备变化时刷新，过期异步查询不能覆盖新选择。正式播放继续核对实际 AudioTrack 路由，拒绝扬声器回退。

权限卡展示实际授权、系统申请、拒绝说明、公开应用详情设置入口；返回后复核。RECEIVE_SMS 安装器受限资格与普通用户授权分别处理，不用 pm grant 伪造授权验收。

后台入口使用公开 ACTION_APPLICATION_DETAILS_SETTINGS；说明 OriginOS7“允许后台高耗电”由用户手动确认且可能增加耗电，不能读取/自动修改厂商策略。点击入口不代表设置已通过。

固定语音测试不接收自定义输入，不含真实验证码，使用同一离线 PCM/AudioTrack/MAY_DUCK/严格路由及清理链。允许在自动播报暂停时主动测试；停止或取消仍会撤销在途会话。回调与真实听感分别记录。

历史阶段0测试控件移入 src/debug 专用非导出 Activity；Release 不含该诊断页面。历史 A/B 代码仍保留但不属于正式产品；正式播报只强制 MAY_DUCK。

## 开机恢复

使用解锁后的凭据保护存储，不声明 directBootAware、不处理解锁前短信、不启动后台 Activity/Service。开启则保留重启前启用或暂停；关闭则在新开机第一次 Application 初始化时通过 Settings.Global.BOOT_COUNT 对账为暂停，早于任何短信处理。BOOT_COMPLETED 只处理状态。相同开机内晚到的开机广播不覆盖用户刚手动启用的状态。

系统若无法提供开机计数，则退回实际开机广播处理，不能承诺广播先于 SMS。厂商可能限制开机广播；强行停止后的广播/自动启动不保证，开机恢复不是保活。真机状态与未观察到的广播分别见验收报告。
