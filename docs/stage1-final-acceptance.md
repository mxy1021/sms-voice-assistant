## A. 新安全用例（先安装本轮构建的两个APK）

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest
adb -s $svaDevice install -r app/build/outputs/apk/debug/app-debug.apk
adb -s $svaDevice install -r -t app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
.\scripts\Test-DebugSms.ps1 -Case Safety
```

本轮安装器返回INSTALL_FAILED_ABORTED（User rejected permissions），新用例**NOT_RUN**；不能在设备上旧APK运行新Case并当新代码通过。待用户方便时正常确认安装，不换签名、不卸载、不清数据、不关闭安全检查。脚本会发现实际runner并握手启动正式界面，所有输入仍标DEBUG_SIMULATION。

| 命令 | 对应原用例 | 触发方式与证据等级 | 本轮状态 |
|---|---|---|---|
| StopDuring | L01 | 真正PCM开始且有焦点后关闭正常运行设置，检查终结/释放/不复活；停止听感另确认 | NOT_RUN，已构建 |
| RulesDuring | R20 | 真正播放中通过正常仓库改规则，验证旧代次许可终止写入；恢复设置不重播 | NOT_RUN，已构建 |
| TtsFailures | L05 | androidTest替身分别给出初始化ERROR、合成onError；检查零PCM及真实TTS对象stop/shutdown调用 | NOT_RUN，CONTROLLED_SUBSTITUTE |
| FocusFailure | L06 | androidTest请求端返回失败，检查零PCM/清理调用；没有取得系统焦点，不宣称Android真的拒绝 | NOT_RUN，CONTROLLED_SUBSTITUTE |
| FocusPermanent | L06 | 用另一个真实AudioManager请求观察实际-1；系统有音乐活动时SKIP，避免打断用户音乐 | NOT_RUN，ANDROID_SYSTEM |

Safety包含以上6个子结果；All现已包含这些非人工子用例，原先22条基线结果保留为历史。App中的新增SpeechDependencies是默认委托平台的普通依赖边界，没有运行时选择器、fixture或故障标志；替身类只在androidTest，Release隔离检查覆盖它们。

受控失败只能证明相应错误处理分支，不证明真实AIService或Android实际产生错误。实际系统-3/GAIN已有上一轮证据，实际-1和真实焦点申请失败本轮均未取得新设备证据。

## B. 需要用户操作的安全测试

1. **L02动态断连**：耳机连接、APP启用，准备好快速断开耳机的操作。运行`-Case DisconnectDuring`。脚本提示后3秒才开始固定语音；听到语音后立即断开，记录是否终止、手机是否泄漏语音。未观察到真实动态条件会SKIP。API取消通过仍需人工确认无扬声器泄漏。
2. **L03切路由**：目标耳机连接，运行`-Case RouteDuring`，在语音中切媒体输出到手机或其他设备。只有实际轨道换路由/取消才有该证据；如果setPreferredDevice仍把轨道留在目标耳机，记录“未发生实际路由变化”，不伪造回调。
3. **T10蓝牙撤权**：在系统正常撤销本应用“附近设备/蓝牙连接”，保留短信权限；撤权可能终止APP进程。之后运行`-Case BluetoothPermission`，应拒绝且无TTS/PCM。工具本身不改权限。再正常授权，刷新并运行Otp确认恢复，检查目标耳机仍保存。
4. **L01/R20听感**：在正常语音中停止/改规则，确认旧语音停止、重新启用不重播；API结果与听感分别登记。

这些命令已编译，尚未取得本轮真机执行结果。动态断连、切输出和实际撤权/恢复仍是强制安全边界，不因替身测试而豁免。

## C. 七条最小真实SMS核心测试

等安全测试和安装准备完成后再分批执行。由另一台正常设备发送新的普通蜂窝SMS，不发模拟广播。可用人工短文本作为真实SMS内容，例如“验证码1234。”、“明天开会。”；这些是建议发送样例，无需把实际正文或码回传。保持短信系统提示音的正常设置，以覆盖原焦点竞争问题。

| 编号 | 操作前配置/设备状态 | 发送及预期 | 覆盖与结果 |
|---|---|---|---|
| H01 | APP前台、启用、筛选开/精简开、目标耳机 | 新短验证码，完整精简语音；原通知音不使语音永久取消 | T03/R02/L06，NOT_RUN |
| H02 | 筛选开/精简关，Home返回桌面 | 短验证码读完整原文；不含摘要替代 | R04/T14，NOT_RUN |
| H03 | 筛选开，Home后锁屏 | 普通短信无本APP语音；系统原短信铃声允许存在 | R03/R05/R11，NOT_RUN |
| H04 | 筛选关，目标耳机播放音乐 | 短普通SMS全文，音乐降低后恢复，无手机语音 | R06/T15/R17/R18，NOT_RUN |
| H05 | 筛选关、精简值保留但禁用 | 短验证码SMS全文，含原有提醒，不改为精简摘要 | R07，NOT_RUN |

七条不是所有45项的替代。H03的“静默”仅指本APP没有语音，不能把正常短信铃声当失败。H06/H07必须用户确认物理断USB，连接ADB时成功不能替代；H07由用户明确确认并实际操作重启，本工具不自动重启。

每条只回报：**编号、是否及时、语音是否完整、音乐是否降低/恢复、有无扬声器泄漏**。不提供真实码、号码、正文或完整Logcat。负向样例可注明“仅系统铃声，无本APP语音”。
