## 自动化

- F1：4/5/6/8位、00981、A12345、大小写、中文/英文模板；金额、日期、手机、订单、普通编号、歧义与不支持长度负例；仅码span替换。
- F2/F3：四组合×验证码/普通短信×有/无联系人；原字符串不变、80/100/120/160 UTF-16、emoji、姓名与拼读扩展计数。联系人授权/拒绝/撤销/异常、不同格式精确同号、短号、字母发送者、无联系人、同号异名。
- 清理：一个/多个URL、中间URL、中文标点、www/裸域名、路径/跟踪参数；验证码、取件码、金额、日期、订单、地址保护。
- 音量：0不建效果、300/600mB、正会话ID、禁止全局0会话、构造/启用失败回退、幂等释放；在真实SpeechSession验证完成/取消/永久焦点丢失的释放及系统媒体音量不变。单测对象释放不能冒充实际音效或听感。
- 队列：P0优先与同级接收FIFO、非抢占、容量/满队列、等待超时finish、过期不播放、配置变更/关闭/断连/撤权清空、不复活。
- 预算：5.0/5.1/5.2秒边界、1MiB、8秒/8.5秒边界。自动化拒绝5.1/5.2不代表已完成扩容实验。

## 真实SMS与人工记录

每次记录构建提交/预算/原设置、source=REAL_SMS、匿名事件ID、场景、完整/逐位/联系人/链接听感、音乐降低和恢复、手机无语音、PCM时长/大小/全量写入、T0～T12、拒绝原因。禁止注入SMS_RECEIVED。

| ID | 场景 | 操作与期望 |
|---|---|---|
| S01 | 5位/前导零/混合 | 真实发送验证码55555、00981、A12345；逐位正确，字母不丢失 |
| S02 | 四组合 | 逐组合发送验证码和普通短信；按需求表，全文也逐位读码 |
| S03 | 联系人 | 用户主动授权后，已存联系人短信读名称＋正文；未存/短号仅正文，无号码 |
| S04 | 撤权与恢复 | 系统撤销联系人后发SMS仅正文；重新主动授权后恢复，蓝牙设置不丢 |
| S05 | 链接及重要内容 | 发含取件码、金额、日期和一个/多个/中间链接短信，链接消失其余完整 |
| S06 | 三档音量 | 相同系统媒体音量/同音乐/同短信比较0/3/6，检查清晰度、失真、爆音和音乐不变 |

## 预算专项（B01～B12）

相同样本分别在8秒和8.5秒候选构建执行：慢TTS初始化、接近5秒PCM、临时焦点丢失恢复、永久丢失、Home、锁屏、静置10～15分钟、真实进程冷启动、音乐、蓝牙中断、播放中停止、连续到达。采集真实finish调用/返回，不以模拟业务回调代替PendingResult。查看真实foreground标志；能取得系统分发起点时检查完整生命周期≤9秒，否则明确不可测。检查ANR/广播阻塞/后续短信延迟。未全通过，正式仍8秒。

只有8.5秒专项通过才实际扩容5.0→5.1→5.2秒，保持1MiB和其余参数；字符80/100/120/160仅实验样本，不自动设置160。

## 耳机及安全回归

M01无音乐、M02音乐、M03Home、M04锁屏：临时MediaSession记录真实KeyEvent，不能假设双击统一映射；须停止本APP语音、音乐继续且不跳曲，不能可靠归因于目标耳机则不通过。M05正常/取消/异常均释放。无真实按键证据记NOT_RUN，不写技术失败。

R01Home、R02锁屏、R03物理断USB静置10～15分钟、R04音乐duck/恢复、R05短信通知音、R06断耳机即停/无扬声器泄漏、R07重连仅新消息、R08播报中关总开关、R09播报中撤蓝牙权限、R10重启解锁不开APP收真实SMS。历史PASS仅为基线，本轮不自动继承。
