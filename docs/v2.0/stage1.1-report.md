# V2.0 阶段1.1技术报告

当前状态：开发中、人工待验收。不是正式通过报告。

六项范围：F1验证码/F2联系人与链接/F3四组合/F5音量由本轮实现；F4预算只允许独立实验，未经真实验证正式保持8秒和5秒PCM；F6只做临时MediaSession技术验证，未满足全部条件不提供正式功能。用户已将方案A队列追加至本轮，参数确认和验证必须单独记录。

原始8秒基线见test-results，旧版finish后标记为5018ms，精确finish调用/系统分发/冷启动完整周期未知。不能以该单条结果判8.5秒通过。冷启动属于系统广播ANR计时，Application入口至finish也不包含此前全部系统分发过程。[官方广播ANR文档](https://developer.android.com/topic/performance/anrs/diagnose-and-fix-anrs)

正式上限仍80 UTF-16、完整PCM5000ms/1MiB、接收8秒（排队和清理包含其中）；扩容未获设备验证，不承诺任意长度完整播报。任何安全中止优先于完成当前语音。

Manifest仅计划增加可选READ_CONTACTS，无联系人权限不影响短信必需权限门禁。轨道级增益代码不修改STREAM_MUSIC，设备实际响度、削波、失真和音乐隔离仍需相同系统音量听验。MediaSession没有通用双击事件或可靠的蓝牙身份归因保证，未实测不作可行承诺。

最终交付需补充构建/测试、修改文件、APK路径与哈希、Git SHA/远端一致性和剩余测试；所有公开文档只保留人工构造内容与脱敏状态。
